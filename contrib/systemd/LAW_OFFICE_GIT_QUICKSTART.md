# Law Office Git Quickstart

This repo is set up so the safe defaults are simple:

1. Update from the official repo:

```bash
git checkout master
git pull upstream master
```

2. Switch back to your law-office changes:

```bash
git checkout lawoffice-recovery-helpers
```

3. Push your branch to your fork:

```bash
git push
```
